# YUDAANT · how to run this in front of judges

Everything here is local: no login, no API key, no internet. The only thing that can fail live is
your own machine, and every section below has a fallback for that.

---

## T-20 min: the pre-flight

```bash
./scripts/demo.sh          # typecheck · tests · build · regenerate every artefact
./scripts/demo.sh --quick  # 20 s: re-verify and print the numbers to quote
```

It ends with `GO` or `NO-GO`, and it prints the **talking points taken from a real run** — quote
those, not your memory, so no number you say can be stale:

```
  pair MEMORY      · Groups               13   0.00     11   0.00    -9.99*
                   · Groups: A 13 vs B 0.00 (Δ -13, effect -9.99*, first divergence round 2)
  determinism      · run 1 fingerprint: 502f503b / records 60   →  tail metrics identical: YES
```

Then:

1. `npm run dev` → open `http://localhost:5173` in a **normal browser tab** (not an embedded pane:
   some in-app webviews block module workers).
2. Click one preset and `⇄ run both` once. This warms V8, and it means the app is already showing a
   finished pair when you start talking.
3. Terminal on the right half with the CLI command already typed (you'll up-arrow to it):
   `npx tsx scripts/simulate.ts --pair --change MEMORY --agents 100 --rounds 200 --seed 1337 --quiet`
4. Browser zoom ⌘/Ctrl `−` twice (the UI is dense by design and reads much better at 80–90 %),
   fullscreen, notifications off, power cable in.

## How the judges watch it

| setup | do this |
|---|---|
| screen share / projector | what the steps above prepare. Everything runs on your box. |
| they get their own link | send the dev-server URL (port 5173). Keep the terminal open; if you close it, the link dies. |
| locked-down or offline | hand over `experiments/pair-memory.html` — one file, self-contained, opens anywhere, with the SVGs and every finding inside. |
| you want the built app, not dev | `npm run build && npm run preview` → port 4173. **Serve it over http**: `dist/index.html` opened from disk cannot load a module worker. |

`experiments/pair-memory.{md,html,csv,bundle.json,pair.json}` are generated by the pre-flight, so
they always match the numbers on screen.

## The 90-second version

| | where | what you say (approximately) |
|---|---|---|
| 0:00 | **Observe** | "A hundred agents, six behavioural coefficients each, gathering, trading, cooperating, forming groups. This is a simulation, not a chatbot — and the point of the app is that every claim it makes is traceable." |
| 0:15 | click any agent → **X-ray** | "Ask it why it did that. Utilities of each action it considered, the weight of every factor, the exact memory records it read. This is the trace written *while* it decided — nothing is narrated afterwards by a language model." |
| 0:35 | **Compare** → `⇄ run both` (≈2 s) | "Two worlds. Same seed, so the first rounds are byte-identical. One setting differs: memory. Now any difference in cooperation has exactly one candidate cause inside the model." |
| 0:55 | the diff table → **Groups** row | "With memory: thirteen groups. Without: zero. Groups cannot form without memory here because founding needs two recorded interactions with the same partner — that's the mechanism, not a story. And it tells me the round they first separated." |
| 1:10 | **Discoveries** → one card | "Every finding ships with its evidence and the command that reproduces it." |
| 1:20 | **Report** → *Threats to validity* | "And it writes its own limitations: single replicate, effect sizes descriptive not inferential, agents are utility maximisers. Here is the next experiment it wants run — one click, and that's the whole loop." |

If you only get to show one screen, show the Compare table. If you get to say one sentence: **"same
seed, one flipped setting, and the report prints the round where the two worlds first parted — along
with the reasons not to over-read it."**

## The 3-minute version

Add, in this order:

1. `▶ guided tour` (status bar) — 7 steps that drive the real app. Start it, advance one step, then
   stop it and continue by hand: "it walks the same path I'm about to take."
2. **Observe** → speed `16×`, `▶ play`: let them watch structure appear for 15 seconds. Say
   "nothing is scripted here — the arcs are how full each resource node is, the rings are group
   membership."
3. **Metrics** → click a tile: full series + the published definition. "Twenty-nine metrics, each with
   its formula. Flat ones too — 'nothing moved' is a result."
4. **Compare** → the `change` selector (memory · communication · reward model · scarcity · deception ·
   **seed only**). Flip to *communication* or *scarcity* and run it live: "same harness, different
   variable, two seconds." Then click **seed only** and run it: the chip turns red and reads
   **not controlled**, with the reason next to it — `seeds differ (1337 vs 1438) — two variables
   changed` — and the interpretation box says the comparison mixes two changes instead of naming a
   cause. Watching the tool refuse to over-claim lands harder than any sentence I could say about
   caution.
5. **Archive** → save the run, restore it. "Lossless bundle — the chart, events, config and report
   come back from one file. That's also my reproducibility claim."
6. **Be an agent** → one paragraph: "you can drive one agent by hand and watch the engine treat your
   choice exactly like its own."

## The 7-minute version (Q&A-proof)

Everything above, plus:

- **Determinism, live, in the terminal** (5 s):
  `npx tsx scripts/simulate.ts --determinism-check --rounds 60 --agents 200` → identical fingerprints.
  Then: `--seed 7` on the pair, to answer "is this seed cherry-picked?" by changing it in front of them.
- **Scale**: `npx tsx scripts/simulate.ts --agents 500 --rounds 120` → `19.75 ms/round` printed.
- **Deception**: preset *Deception and detection* (10 of 100 agents seeded with deceptive strategies) →
  Metrics tab, the three rows *Deception detected* / *Deception missed* / *False accusations*. "The
  observer never gets a ground-truth label in the decision path, so 'detected' is a real outcome, not a
  giveaway."
- **The refusal, on purpose**: Compare → `seed only` → `⇄ run both`. Two seconds later the chip reads
  `not controlled`, `pairQuality` names the second variable, and the `plain-text report` disclosure at the
  bottom prints `⚠ not verified as a clean pair`. Nothing was filtered or hidden — that rule lives in
  `compare.ts` / `state/derive.ts`, and it is what makes the well-formed pair worth believing.
- **Printable proof**: open `experiments/pair-memory.html` from disk while it's still on screen.

## When something goes wrong

| symptom | what to do | say |
|---|---|---|
| status bar logs `worker unavailable` | the world is still buildable headless: `⏭ headless` / `⇄ run both` | "the drawing runs in a Web Worker; the simulation doesn't need it — watch the same run headless." |
| app looks blank / stuck spinner | reopen in a real browser tab, hard reload; if still dead, `npm run build && npm run preview` → 4173 | — |
| machine is slow | `agents 60`, speed `16×`, or run headless (≈50× faster) | "it's 4.7 ms a round, so I'll just run it to completion." |
| dev server died and you're mid-demo | the terminal CLI, or the HTML artefact | "fine — here it is as data instead of pixels." |
| judge asks for a variable the UI doesn't offer | `--change FOOD` (MEMORY · COMMUNICATION · REWARD · FOOD) | "one line." |
| "can you show me an LLM in it?" | **About** tab → the optional provider, off by default | "deliberately: a model may add one labelled commentary paragraph, capped, and it can never touch a decision. The measurements are all computed." |

Practice the failure once: with the dev server stopped, confirm `experiments/pair-memory.html` opens and
carries the same numbers. That single rehearsal removes most of the risk.

## Judge crib — the answers, one line each

- **"Why isn't this an LLM?"** Because the question I can answer rigorously is about mechanism design —
  what memory, payoffs and information access do to a population of optimisers — and that needs a model
  whose every term is inspectable. Swapping in a language model buys rhetoric, not measurement.
- **"Isn't the group result hardcoded?"** No: the founding rule needs ≥2 recorded interactions with the
  same partner and positive trust. I can break it live — flip to the reward pair and watch the same gate
  behave differently.
- **"How do I know this seed isn't cherry-picked?"** `--determinism-check`, then `--seed 7` in front of
  you — and *seed only* exists in the Compare tab precisely so a seed change gets labelled as a change
  instead of being smuggled into a result.
- **"What's the novelty?"** The harness, not the finding: trace-at-decision-time x-ray, a config differ
  that must be exactly one key deep, first-divergence round, and exports that a stranger can re-run.
- **"Internal validity?"** The pair is only labelled attributable when the two configs differ in one
  non-cosmetic key with the same seed and same round count — otherwise it says so and stops.
- **"External validity?"** None claimed. It's a mechanism demonstration; the limits section is in the report,
  not in my mouth.
- **"How do you know the metrics aren't fudged?"** Every one has a published formula in the Metrics tab, and
  the analysis layer reads the same packed payload the charts do — that round-trip is a test.
- **"Scale?"** 4.72 ms/round at 100 agents, 19.75 ms/round at 500, single thread; frames go to the canvas as
  transferable typed arrays, so React isn't in the loop.
- **"Tested?"** 31 tests — engine invariants, analysis, jsdom UI — plus `npm run shots`, which drives the
  real app in headless Chromium through every tab and fails on any console error. Between them they found
  seven bugs I would otherwise have demoed: memoryless agents founding groups, a control condition that
  still remembered, unclamped stocks, float noise reported as a finding, a React render loop, a sticky
  table header swallowing the status-bar clicks, and detections listed twice.
- **"What would change your mind?"** A divergence that survives three seeds, an effect that stays when the
  founding gate is removed, or a metric that a partner prefers to smooth. The tool prints exactly those as
  the next experiments.

## Don't say

- "The agents learned / developed trust / understood each other." They update a decayed ledger.
- "Memory causes cooperation." Memory *preceded* a 13-vs-0 group difference in one seeded pair.
- "Emergent" without the threshold it crossed, or "significant" without replication.

If you slip, correct it out loud — it costs a sentence and buys the whole room's trust.
